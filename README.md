# Personal Portfolio Website

## About the Project
This is my personal portfolio website developed using HTML, CSS, and JavaScript as part of my CodeAlpha internship.

The website showcases my introduction, technical skills, projects, resume, and contact information through a clean and responsive design.

## Features
- Personal introduction (About Me)
- Skills showcase
- Projects section
- Resume section
- Contact information
- Responsive layout
- Smooth scrolling
- Hover effects and animations
- Interactive elements using JavaScript

## Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling, layout, and animations
- **JavaScript** – Interactive functionality

## Project Structure
```text
CodeAlpha_Portfolio/
│
├── MyPortfolio.html
├── style1.css
├── script1.js
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `MyPortfolio.html` in your web browser.
4. Explore the portfolio website.
